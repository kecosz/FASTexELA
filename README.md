# FASTexELA
This GitHub repository is intended to make publicly available the code required to reproduce the analyses in Suzuki et al., “Major microbiota transitions across liver disease progression are linked by key mediator taxa connecting host environments and microbial community structures.”  
  
To view the code, please open the Google Colab notebook `amed_FAST_rELA0_74.2_.ipynb`.  
  
To actually run the code, open the file and select “Open in Colab” > “File” > “Save a copy in Drive” to save a copy to your own Google Drive.
